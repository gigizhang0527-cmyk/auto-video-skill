## 🛠️ 核心工作流 (重要)

**本项目严格遵循以下顺序，请勿更改：**

1.  **文案脚本**：生成旁白文案。
2.  **TTS 语音 (小米 MiMo)**：生成旁白音频。
3.  **SRT 时间轴 (Whisper)**：
    *   对旁白音频进行语音识别，生成精准的 SRT 字幕。
    *   **关键**：SRT 时间轴是后续所有视觉生成的**主时间轴**。
4.  **镜头切分**：
    *   根据 SRT 的时间点和语义，将视频切分为多个场景（镜头）。
    *   每个镜头对应一段 SRT 时间。
5.  **参考图生成 (炳火 API)**：
    *   使用 **GPT IMAGE 2.5** 为每个镜头生成静态参考图。
    *   **关键**：同一场景必须使用图生图链，保证一致性。
6.  **视频生成 (Agnes API)**：
    *   **必须使用 Agnes** 的**参考图模式**。
    *   输入：参考图 + 动作提示词 + 时长 (来自 SRT)。
7.  **音频检测**：
    *   检测并去除 Agnes 生成的随机背景音乐（保留音效）。
8.  **总装 (FFmpeg)**：
    *   拼接视频、旁白音频、字幕。

## 🔑 API 职责划分

| 服务 | 职责 | 模型/说明 |
|------|------|-----------|
| **小米 MiMo** | TTS | 语音合成 |
| **Whisper** | SRT | 语音转文字 (本地) |
| **炳火 API** | 生图 | **仅限 GPT IMAGE 2.5** |
| **Agnes** | 生视频 | **必须使用参考图模式** |

## ⚠️ 避坑指南

*   ❌ **错误**：先画图再定时间。
    *   ✅ **正确**：先生成 SRT 确定时间，再画图。
*   ❌ **错误**：使用文生视频。
    *   ✅ **正确**：必须使用参考图模式。
*   ❌ **错误**：忽略音频检测。
    *   ✅ **正确**：必须检测并处理 BGM。
