# 🎬 全自动视频创作 Skill

这是一个通用的 **全自动视频创作** 自动化工作流 Skill。

## 🚀 一键安装

将以下**完整指令**发送给您的 AI Agent：

```
帮我安装这个项目，安装完成后自动运行配置向导：
https://github.com/gigizhang0527-cmyk/auto-video-skill
```

## 🛠️ 核心工作流 (重要)

**本项目严格遵循以下流程，Agent 请勿擅自更改：**

1.  **文案脚本**：生成旁白文案
2.  **参考图生成 (炳火 API)**：
    *   使用 **GPT IMAGE 2.5** 生成高质量静态参考图
    *   每个场景生成一张关键帧
3.  **TTS 语音 (小米 MiMo)**：
    *   使用 MiMo TTS 生成旁白音频
4.  **视频生成 (Agnes API)**：
    *   **必须使用 Agnes** 进行视频生成
    *   **必须使用参考图模式**：将步骤 2 生成的图片作为参考图输入 Agnes
    *   **禁止使用文生视频**：不要只给文字描述，必须给图
5.  **总装 (FFmpeg)**：
    *   拼接视频、音频、字幕

## 🔑 API 职责划分

| 服务 | 职责 | 模型/说明 |
|------|------|-----------|
| **炳火 API** | 生图 | **仅限 GPT IMAGE 2.5** (不要用它生视频) |
| **小米 MiMo** | TTS + 审片 | 语音合成、画面质量检查 |
| **Agnes** | 生视频 | **必须使用**，输入为参考图 + 提示词 |

## ⚠️ 常见错误 (Agent 必读)

*   ❌ **错误**：使用炳火 Seedance 生视频。
    *   ✅ **正确**：使用 Agnes 生视频。
*   ❌ **错误**：使用文生视频 (Text-to-Video)。
    *   ✅ **正确**：使用图生视频 (Image-to-Video)，即参考图模式。
