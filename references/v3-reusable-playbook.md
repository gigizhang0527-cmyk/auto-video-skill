# V3 可复用剧本：GPT 生图 + Agnes 生视频

## 核心流程

1.  **文案脚本**：锁定旁白文案。
2.  **参考图生成 (炳火 GPT IMAGE 2.5)**：
    *   每个场景生成 1 张主图 (Prompt: 场景描述 + 风格 + 角色)。
    *   **关键**：同一场景的不同镜头，必须从主图衍生 (Image-to-Image)，禁止各自文生图。
3.  **TTS 语音 (小米 MiMo)**：
    *   生成旁白音频。
4.  **视频生成 (Agnes Reference Mode)**：
    *   **必须使用参考图模式**。
    *   **输入**：参考图 (步骤2生成) + 动作提示词。
    *   **关键**：提示词必须描述「动作过程」，而不是「状态」。
5.  **音频处理**：
    *   Agnes 生成的视频可能带有随机背景音乐。
    *   **必须检测**：静音帧占比 < 15% 则判定为有 BGM，需重出或去 BGM (保留音效)。
6.  **总装 (FFmpeg)**：
    *   拼接视频、音频、字幕。

## 避坑指南

1.  **画面不一致**：不要各自文生图，必须用图生图链。
2.  **动作僵硬**：提示词必须写「过程」（如：指针从低到高），不要只写「状态」（如：指针在高位）。
3.  **比例错误**：提示词必须带「竖版 9:16」前缀。
4.  **Agnes 400 错误**：单段时长不要超过 12 秒。
5.  **BGM 干扰**：不要相信「静音」提示词，必须跑脚本检测静音帧占比。
