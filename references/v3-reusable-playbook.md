# V3 可复用剧本：SRT 驱动的视频制作流程

## 核心原则

**SRT 时间轴是所有视觉生成的基准**。必须先有精准的时间轴，再进行视觉创作。

## 标准流程

1.  **文案脚本**：
    *   锁定旁白文案。
2.  **TTS 语音生成 (小米 MiMo)**：
    *   生成旁白音频文件 (mp3/wav)。
3.  **SRT 时间轴生成 (Whisper)**：
    *   对旁白音频进行语音识别。
    *   生成带时间戳的 SRT 文件。
    *   **校正**：修正识别错误，保留时间戳。
4.  **镜头切分与规划**：
    *   根据 SRT 时间点，将视频切分为多个场景。
    *   每个场景的时长 = SRT 片段的时长。
    *   输出：`镜头规划表` (场景ID, 开始时间, 结束时间, 时长, 内容摘要)。
5.  **参考图生成 (炳火 GPT IMAGE 2.5)**：
    *   根据每个场景的内容摘要，生成静态参考图。
    *   **一致性**：使用图生图链，避免画面跳变。
    *   **图片传递**：首选 Base64 Data URI，备选 GitHub URL。
6.  **视频生成 (Agnes Reference Mode)**：
    *   **输入**：参考图 (Base64/URL) + 动作提示词 + **SRT 确定的时长**。
    *   **关键**：必须使用参考图模式。
    *   **注意**：免费用户需间隔 60 秒。
7.  **音频检测与处理**：
    *   检测 Agnes 视频是否带有随机 BGM。
    *   如果有，需重出或去 BGM (保留音效)。
8.  **FFmpeg 总装**：
    *   按 SRT 时间轴拼接视频片段。
    *   叠加旁白音频。
    *   烧录 SRT 字幕。

## 为什么要 SRT 驱动？

*   **音画同步**：视觉必须跟随语音节奏，而不是语音追赶视觉。
*   **成本控制**：先确定时长，再生成视频，避免生成过长或过短的无效片段。
*   **精准切分**：根据语义和停顿切分镜头，比固定时长切分更自然。
